Route Tracker

Ferramenta de rota — André

Insere os endereços na ordem de visita, calcula distância e tempo entre paragens, e obtém a hora de chegada a partir de uma hora de início e uma pausa. Endereços que a API não reconheça podem ser corrigidos com um alias de coordenadas GPS. A chave da API fica guardada no servidor, nunca no browser.

01 Ponto de partida e chegada
02 Endereços
Precisas de estar num endereço até uma certa hora? Acrescenta | HH:MM no fim dessa linha (ex: "Rua X, Cidade | 12:00").

03 Aliases de coordenadas
Se um endereço não for reconhecido, define aqui o texto exato tal como aparece na lista, e a coordenada GPS a usar em vez dele (formato: latitude,longitude). Ficam guardados no servidor, sobrevivem a recarregar a página.
04 Endereços interditos
Endereços onde a entrega é feita a pé (rua estreita, telhado, terra batida, acesso interdito à carrinha). Ficam guardados no servidor, e os troços que os envolvem são calculados automaticamente a pé em vez de de carro.
Se souberes onde a carrinha consegue estacionar perto deste endereço, o troço divide-se automaticamente em carro até lá + a pé até à porta. Sem isto, o troço inteiro é calculado a pé.
05 Horas de entrega
Para clientes habituais com uma hora limite fixa, define aqui o endereço e a hora (ex: até às 10:00). Fica guardado no servidor e aplica-se sempre que esse endereço aparecer numa rota — sem teres de escrever "| HH:MM" na lista todas as vezes. Uma hora escrita diretamente na lista de endereços (secção 02) tem sempre prioridade sobre isto.
06 Horário
Tempo gasto em cada endereço (ex: entrega, descarga). Aplicado a todas as paragens exceto a primeira (ponto de partida).
07 Dados guardados
As distâncias já calculadas ficam guardadas para não pagares duas vezes pelo mesmo troço. Se souberes que uma estrada mudou (obras que acabaram, sentido alterado), limpa aqui para forçar valores novos.
